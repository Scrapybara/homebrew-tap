# Scrapybara Homebrew tap

Homebrew casks for [Capy](https://capy.ai/).

## Install

```sh
brew install --cask scrapybara/capy/capy
```

## Update

```sh
brew upgrade --cask capy
```

Capy also updates itself in place, so `brew upgrade` is only needed to keep Homebrew's version bookkeeping current.
